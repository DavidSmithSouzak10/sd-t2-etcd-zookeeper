# Relatório — fontes

Cada arquivo `NN-*.md` é uma seção obrigatória da §10 do roteiro (15–25 páginas, ABNT, com capa e sumário).
A versão final (PDF/DOCX) é montada a partir destes arquivos no fim.

- `notas/diario.md` — diário de bordo: o que foi feito em cada sessão, resultados, problemas (fonte das seções 4, 5, 9).
- `notas/achados.md` — observações que respondem Q/S, já ligadas à evidência.
- `notas/prints.md` — capturas de tela a tirar (o que, quando, para qual seção).
- `figuras/` — prints e diagramas exportados usados no texto.
